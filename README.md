# harry-potter-script
This data analytics project is focused on a comprehensive analysis of the Harry Potter movie scripts. It explores various aspects such as the frequency of dialogues in different movies, the use of spells, the popularity of locations, and the relationship between the films' profits, runtime, and release year. The project employs data visualisation and data manipulation techniques using the 'ggplot2' and 'dplyr' packages in R. The project also seeks to answer several questions to extract insights from the data.
